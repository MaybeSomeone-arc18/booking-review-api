The full demo loop

  1. Log in as customer and create a booking against provider id 2.
  2. Log in as provider: confirm it, then complete it. The status badge moves through the lifecycle.
  3. Back as customer: review the completed booking (rating 1-5).
  4. As provider, hit Summarize my reviews - the job goes onto a Redis queue, a background worker writes the result, and the page polls until it lands.
How it's wired
This pagevanilla JS, fetch -> FastAPIJWT auth, RBAC per role -> PostgreSQLusers, bookings, reviews -> Redisbooking cache, rate limits, job queue -> Workerwrites summaries back
Cross-tenant reads return 404 on purpose, only completed bookings can be reviewed, duplicate reviews hit a DB uniqueness constraint (409), and 20+ creates in a minute trip a Redis rate limiter (429). Swagger docs at /docs.
